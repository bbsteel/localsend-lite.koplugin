# Changelog

## [0.1.4](https://github.com/bbsteel/localsend-lite.koplugin/releases/tag/v0.1.4) — 2026-11-20

- Select multiple files directly in the send picker and submit them as a single transfer.
- Keep selections when paging within a folder. Clear them when navigating to another folder.
- Preview the batch list or long-press a file to view its details, a text excerpt, or an available cover.
- Keep the device list open after sending so the same batch can be reused or replaced.

## [0.1.3](https://github.com/bbsteel/localsend-lite.koplugin/releases/tag/v0.1.3) — 2026-11-19

- Keep a fixed LocalSend Lite title above the receive status.
- Highlight device nicknames with corner brackets in discovery and transfer dialogs.
- Show a bulleted file list in the receive confirmation and paginate batches at five files per page. Accepting from any page accepts the whole batch.
- Add KOReader emulator screenshots to the English and Chinese READMEs.

## [0.1.2](https://github.com/bbsteel/localsend-lite.koplugin/releases/tag/v0.1.2) — 2026-11-18

- Display the current file, transfer progress and speed while receiving.
- Add Simplified and Traditional Chinese interface translations.
- Run Kindle firewall commands asynchronously and add rotating diagnostic logs.

## [0.1.0](https://github.com/bbsteel/localsend-lite.koplugin/releases/tag/v0.1.0) — 2026-11-18

- Publish the initial lightweight KOReader plugin for LocalSend file transfers and automatic device discovery.
